# Web Development Learning Journey

This repository records my progress as I learn web development step by step.

## Learning order

1. **HTML** — page structure and content
2. **CSS** — styling, layout and responsive design
3. **JavaScript** — interactivity and programming fundamentals
4. **React** — frontend applications (after JavaScript fundamentals)

I will add notes, examples and small practice projects as I learn. I will only mark a topic complete after practising it myself.

## Folder structure

- `HTML/` — HTML notes, tags, attributes, examples and practice
- `CSS/` — CSS notes, selectors, properties, layouts and practice
- `JavaScript/` — JavaScript notes, concepts, examples and practice

## Progress checklist

- [ ] HTML basics
- [ ] CSS basics
- [ ] JavaScript basics
- [ ] Build a small webpage using HTML and CSS
- [ ] Add interactivity with JavaScript
- [ ] Build a personal portfolio

## My study rule

Learn one concept, write the code myself, test it, and then record the definition and example here.
